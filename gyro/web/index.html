The camera does not record which lens was on it, so the profile needs these two from you. Distortion is left at zero — the profile is still worth having, because what actually matters for rolling shutter is the readout time, and that comes from the sensor mode in the file.

What the file is

Sixty-four bytes of header and then nothing but 8-byte records — gyroscope and accelerometer interleaved in the order they happened, exactly as the camera's buffers reached the card. The gyro runs at 2499.466 Hz, so the log sets tscale to the sample period itself and counts samples in t: nothing rounds and nothing drifts.

No .GYR beside a clip?

The volume you recorded to needs a folder called GYRO in its root — the SD card and, if you record to one, the USB SSD as well. The camera will not create it, and formatting removes it.

The accelerometer

It is in the .GYR either way, about forty-six readings a second against the gyro's twenty-five hundred. It is out of the log by default because it made Gyroflow's fusion worse in the test that settled the axis order — but horizon levelling needs gravity, so there is a switch for it on each take.
