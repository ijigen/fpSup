Sensor Lab-IMX410

Choose the sensor crop, resolution, frame rate and readout recipe from the Quick Set. The camera records CinemaDNG in exactly that mode.

在快速設定（QS）選感光元件裁切、解析度、幀率與讀取配方，相機就照這個模式錄 CinemaDNG。

Test build測試版 · Open the simulator開啟模擬器 ↗

What it is產品介紹

The SIGMA fp’s sensor, the Sony IMX410, can be read in many more ways than the stock menu offers. Sensor Lab opens them up: you pick the area of the sensor to use, the size to record, the frame rate and how the sensor is read, and the camera records CinemaDNG that way.

SIGMA fp 的感光元件 Sony IMX410 能用的讀取方式，比原廠選單提供的多得多。Sensor Lab 把它們開放出來：你決定用感光元件的哪一塊、錄多大、幾格、怎麼讀，相機就照這樣錄 CinemaDNG。

  • Any crop — open gate (full 3:2 sensor), HD, S35, APS-C, S16, square, or your own width and height.
  • Any resolution — common sizes from 1K to 6K, or your own width and height, down to the pixel grid the sensor allows.
  • Real pixel merges — 2x2, 3x3, 6x6, 1x2 and 1x3 for smaller files from the same field of view.
  • Higher frame rates — up to what each crop and size can reach, with fine-tuning.
  • Readout recipes, including 14-bit — choose how the sensor is read: 11, 12 or true 14-bit conversion, sensor and ISP merging, each with its rolling-shutter time.
  • Recorded bit depth and data rate — CinemaDNG 8, 10, 12 or 14-bit, with MB/s shown before you record.
  • Simulator and QR — plan a mode in the browser and send it to the camera with a QR code; scan the camera’s code to see the details of the current mode or share it.
  • 任意裁切：Open Gate（整片 3:2 感光元件）、HD、S35、APS-C、S16、正方形，或自訂寬高。
  • 任意解析度：1K 到 6K 的常用尺寸，或自訂寬高，細到感光元件允許的像素格。
  • 真正的像素合併：2x2、3x3、6x6、1x2、1x3，同樣視野、檔案更小。
  • 更高的幀率：開到每個裁切與尺寸能達到的上限，還能細調。
  • 讀取配方，含 14-bit：自己選感光元件怎麼讀：11、12 或真 14-bit 轉換，感光元件與 ISP 的合併方式，各自顯示捲簾時間。
  • 錄製位元深度與資料率：CinemaDNG 8、10、12、14-bit，錄之前就看得到 MB/s。
  • 模擬器與 QR：先在瀏覽器規劃模式，再用 QR 碼送進相機；掃相機上的碼可查閱目前模式的細部資料，也能分享給別人。

It is a laboratory. Sensor Lab aims to open up every format the sensor can deliver and everything the ISP can do with it. It does not promise that the card’s write speed or the camera’s CPU can keep up with the mode you choose: some combinations drop frames, stop recording or cannot be recorded for long. Test a mode before you rely on it.

它是一間實驗室。Sensor Lab 的目標是盡可能解放感光元件的所有格式與 ISP 的能力，但不保證卡片的寫入速度和相機 CPU 承受得了你選的模式：有些組合會掉幀、停錄，或錄不久。正式使用前請先試拍。

Install安裝

Select Sensor Lab-IMX410 in fpSup-Merge and follow its installation steps. The page adds QS-Share, which Sensor Lab needs. SIGMA fp firmware Ver.5.02 only. It cannot run together with RES-Custom.

在 fpSup-Merge 勾選 Sensor Lab-IMX410，依頁面說明安裝。頁面會自動附上它需要的 QS-Share。只支援 SIGMA fp 韌體 Ver.5.02，不能和 RES-Custom 同時使用。

1. The tiles on the Quick Set1. 快速設定上的格子

On the CINE Quick Set, the stock DC, RES, FPS and FORMAT tiles become Sensor Lab’s automatically. Three more are new and you add them yourself: RECIPE, MB/s and QR. Go to MENU → SYSTEM → Custom QS [CINE], pick a slot, press OK and choose from the list. If you removed DC, RES, FPS or FORMAT from your Quick Set earlier, put them back the same way. CINE only.

CINE 快速設定上原廠的 DC、RES、FPS、FORMAT 格會自動換成 Sensor Lab 版。另外三個是新增的，要自己加：RECIPE、MB/s、QR。到 MENU → SYSTEM → Custom QS [CINE]，選一格、按 OK，從清單挑。之前把 DC、RES、FPS、FORMAT 從快速設定拿掉的話，用同樣方式加回來。只有 CINE 模式有效。

2. Set the mode in this order2. 依這個順序設定

  • DC — the sensor crop: OG, HD, S35, APS-C, S16 or square. Changing DC resets RES.
  • RES — the recorded size. An entry whose hint shows a merge such as “2x2” or “3x3” is a real pixel merge; “+RW” means the camera’s scaler is used as well.
  • FPS — frame rates the chosen crop and size cannot reach are greyed.
  • RECIPE — the readout method for that size and frame rate, with its rolling-shutter time (RS).
  • FORMAT — the recorded bit depth. MB/s shows the data rate, so you can tell whether the card will keep up.
  • DC：感光元件裁切，有 OG、HD、S35、APS-C、S16、正方形。換 DC 會重設 RES。
  • RES：錄下的尺寸。提示寫著「2x2」「3x3」這類合併的項目是真正的像素合併；帶「+RW」表示還用到相機的縮放。
  • FPS：目前的裁切與尺寸達不到的幀率會反灰。
  • RECIPE：這個尺寸與幀率下的讀取方式，並顯示捲簾時間（RS）。
  • FORMAT：錄製的位元深度。MB/s 顯示資料率，可以先看卡片跟不跟得上。

Example: DC OG, then the RES entry marked “2x2” (3024×2020) records 3024×2014 with the scaler off. On S16, “2x2” records 1040×620.

例：DC 選 OG，RES 選標著「2x2」的那項（3024×2020），錄出 3024×2014，不經縮放。S16 的「2x2」錄出 1040×620。

Controls操作

  • Front dial: one step. Rear dial: ten steps. The list at the bottom holds the common values.
  • AEL on DC, RES or RECIPE opens more options (width, height, ratio lock, ADC, binning). AEL again goes back.
  • AEL on FPS fine-tunes the frame rate in place; the tuned value stays in the list in yellow.
  • Every step takes effect at once. The mode is applied again each time the camera starts; you do not need to open the Quick Set.
  • 前轉盤一次一步，後轉盤一次十步。下方清單是常用值。
  • 在 DC、RES、RECIPE 按 AEL 進入更多選項（寬、高、比例鎖、ADC、合併方式）；再按 AEL 返回。
  • 在 FPS 按 AEL 是原地細調幀率；細調出的值會以黃色留在清單裡。
  • 每轉一步立刻生效。每次開機會自動再套用，不用先開快速設定。

Simulator and QR模擬器與 QR

The simulator is the same Quick Set in a browser, with the full details of each mode. The QR tile on the camera shows a code; scan it with a phone to open the simulator with the camera’s current settings. Use it to look up the details of the mode you are in, or pass the link on to share that mode with someone else.

To send settings the other way, press AEL on the QR tile and point the camera at the simulator’s QR code. The settings apply at once. This does not work while recording.

模擬器是瀏覽器裡的同一套快速設定，並列出每個模式的完整細節。相機上的 QR 格會顯示一個碼，用手機掃它，就以相機目前的設定打開模擬器。可以用來查閱目前模式的細部資料，也可以把連結傳給別人，分享這個模式。

反過來要把設定送進相機：在 QR 格按 AEL，把相機對準模擬器上的 QR 碼，設定立刻套用。錄影中不能掃。

Recording at high frame rates高幀率錄影

High frame rates are limited by the camera’s CPU as well as the card: each frame costs processing time whatever its size, so frames can drop or the recording can stop even when MB/s is within what the card can take. Try these in order:

高幀率除了卡片速度，還會受相機 CPU 限制：不論畫面多小，每一幀都要花處理時間，所以即使 MB/s 在卡片能負擔的範圍內，仍可能掉幀或停錄。可以依序試：

  1. Install Early Flush and Unlock Writer (tick them in fpSup-Merge).
  2. Set Memory Media → USB Storage → Write Mode to Custom.
  3. Turn off all on-screen display.
  4. Turn off Gyro.
  5. Try a different SSD enclosure.
  1. 安裝 Early Flush 和 Unlock Writer（在 fpSup-Merge 勾選）。
  2. 把 Memory Media → USB Storage → Write Mode 設成 Custom。
  3. 關掉所有畫面顯示（UI）。
  4. 關掉 Gyro。
  5. 換一個 SSD 外接盒試試。

Good to know注意事項

  • CINE with CinemaDNG only. If the camera is set to MOV the mode is not applied; switch to CinemaDNG.
  • High data rates shorten how long an SD card can record; check MB/s.
  • Some formats cannot be played back in the camera.
  • Known issue: OG 6x6 can place its first frame about 2 rows off. Later frames are fine.
  • Updating from SensorLab 0.7.x or QS Container: delete SensorLab-IMX410_v0.7.*.BIN and QSContainer_v*.BIN from the card’s fpSup folder first. Settings start from the defaults.
  • In the Custom QS list, the RECIPE, MB/s and QR entries still show the DC icon. The Quick Set itself shows their names.
  • 只在 CINE 的 CinemaDNG 有效。相機設成 MOV 時不會套用，請改成 CinemaDNG。
  • 資料率高會縮短 SD 卡能錄的時間，請看 MB/s。
  • 部分格式無法在機內回放。
  • 已知問題：OG 6x6 的第一幀可能錯位約 2 列，之後的幀正常。
  • 從 SensorLab 0.7.x 或 QS Container 更新：先刪掉卡上 fpSup 資料夾裡的 SensorLab-IMX410_v0.7.*.BIN 與 QSContainer_v*.BIN。設定會回到預設。
  • 自訂 QS 的清單裡，RECIPE、MB/s、QR 三項的圖示仍是 DC 的；快速設定本身會顯示各自的名稱。
