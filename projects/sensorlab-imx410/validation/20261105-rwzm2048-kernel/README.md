# RWZM 2048(2:1)的實際核 —— 離線量測

2026-11-05,離線,未碰相機。回答 Bei 的問題:RWZM 2048 水平 2:1 是不是同色等權重合併
`(a+b+1)>>1`?還是單相位三角核 `[0.13,0.76,0.13]`?

承接 `projects/open-gate/notes/REDUCTION_KERNEL_MEASURED.md` §7.5.3 / §7.5.6 的
「整數比例的核是外插的,真正的證明要一支 RWZM2048 實錄」。

## 0. 結論

**兩個都是,看顏色。** RWZM 2:1 在**感光元件座標**上取均勻網格(輸出第 X 行 ↔ 輸入
`2X + 常數`),再用**同色**樣本內插。2:1 下同色樣本間距是 2,所以:

| 輸出位置 | 落點 | 相位 | 水平核(同色平面樣本) |
|---|---|---|---|
| 偶數感光行 (R、G2) | 正好在一個同色樣本上 | 0 | **三角 ≈ `[0.12, 0.75, 0.12]`**(雜訊推得中心 ≈0.78–0.80) |
| 奇數感光行 (G1、B) | 兩個同色樣本正中間 | 8/16 | **等權重 2 抽頭 ≈ `[0.51, 0.49]`** |

垂直 2:1(z2048)完全對稱:偶數列 (R、G1) 相位 0、奇數列 (G2、B) 相位 8,核相同 → RWZM 等向。

所以 z2048(兩軸 ÷2)的四個色平面各吃不同的核:

| 平面 | H × V | 等效 |
|---|---|---|
| **B** | 2 抽頭 × 2 抽頭 | **真 2×2 等權重合併**(2D 擬合四格 0.238/0.254/0.252/0.232) |
| G1 | 2 抽頭 × 三角 | 半合併 |
| G2 | 三角 × 2 抽頭 | 半合併 |
| **R** | 三角 × 三角 | **近似點取樣**(中心 ≈0.6,只有輕微模糊) |

- **幾何是對的,沒有 D7 那種成對錯位。** 四個平面的質心都落在同一個均勻網格:
  水平 `ref_col = 2X + 8`、垂直 `ref_row = 2Y`(z1024 DNG 座標)。殘差位移 ≈ −0.01~−0.02
  平面樣本(≈ −0.03 感光像素),可忽略。這和 OG3K 感測器合併的 `1,3,1,3` 成對網格不同。
- **代價是逐色不同的 MTF/疊紋/雜訊**:R 幾乎不降雜訊也不濾波,B 是完整 2×2 平均。
  去馬賽克後會變成顏色相關的銳利度與疊紋差。
- 相位 0 的核本身**不是 delta**,是輕微的三角模糊 —— 和 §7.5 從 25/16 解出的原型一致。
- 推論(未實測):奇數整數比(3:1)每一色都落在相位 0 → 全部是三角核、近似點取樣,
  與 ISP_CAPABILITY_MAP §0.5「z3072 雜訊 3.22 反而高、單點抽樣」吻合。
  偶數整數比只有一半的顏色拿到平均。

**回答 Bei:不是。** RWZM 2048 不是同色等權重 2:1 合併;只有 G1、B(水平)/G2、B(垂直)
那一半剛好是等權重 2 抽頭,R、G2(水平)是單相位三角核。四色只有 B 在 z2048 是真 2×2 平均。
捨入 `(a+b+1)>>1` 無法從這組資料判定(不同次錄影,沒有同一幀可比)。

## 1. 素材

`projects/isp-lab/validation/20261027-night1-*`,FHD 29.97 路線 row 122 / mode 106,ISO 3200,
三案各 3 幀 CinemaDNG(12-bit MSB-first 打包、RGGB、BlackLevel ≈255.9、單一 strip):

| 案 | RWZM (H×V) | DNG | 幀 |
|---|---|---|---|
| z1024 | 1023×1023(原廠 1:1) | 3024×1708 | cdng_0000{24,25,26} |
| z2048x1024 | 2048×1023 | 1504×1708 | cdng_0000{15,16,17}(strip 尾多 12 bytes 填充) |
| z2048 | 2048×2048 | 1504×854 | cdng_0000{12,13,14} |

取出:`python3 projects/isp-lab/host/evidence_jxl.py unpack validation/RUN DEST push/`
(z1024 的幀在 `evidence.cdngt`,另兩案在 `evidence.side.tar.zst`;工具會驗 sha256)。
本次放在 scratchpad `rwzm2/<case>/push/`,`rk_load.py` 的 `ROOT` 或環境變數 `RWZM2_DIR` 指過去。

場景:夜間室內絨毛玩偶,曝光足(G 均值 ≈240 DN 扣黑),但**高頻紋理弱**:參考平面的二階差分
變異數,R/B 訊號 ≈10 對 3 幀平均的雜訊 ≈27,G ≈45 對 ≈50 —— 接近 Nyquist 的 SNR ≈1。
因此一般最小平方會嚴重衰減(見 §3),必須用工具變數法。左 1/3 畫面紋理太少,擬合不穩(sd 到 0.2–5),
只用全幅與右 1/3。

## 2. 對位

`rk_register.py`:2 抽頭盒子預測 + 高通相關,整數搜尋。z2048x1024:R/G2 `s=3`、G1/B `s=4`,dy=0;
z2048 另外 R/G1 `dy=−1`、G2/B `dy=0`。粗對位分成兩群本身就是「兩個相位」的第一個訊號;
自由抽頭擬合後四色的質心收斂到同一感光網格(§0)。三等分畫面的 s 一致 → 參考的 1023
沒有可見的比例誤差。

## 3. 核(工具變數最小平方)

`rk_iv.py`:回歸變數用參考的一幀、工具變數用另外兩幀的平均(同訊號、獨立雜訊),三種選法取平均
→ 不需要知道 σ、沒有衰減偏差。`rk_fit.py` 是另一條路(3 幀平均 + EIV 扣 σ²/3),結果一致。

**z2048x1024,水平邊際(同色平面樣本,參考索引 2x+3+k,k=−2..3):**

| 平面 | r² | 水平核 | 質心(相對 2x+3) | 偶數 x / 奇數 x |
|---|---|---|---|---|
| R  | 0.99908 | `+.007 −.002 +.131 +.736 +.119 +.008` | +0.987 | 相同(.738 / .734) |
| G1 | 0.99966 | `+.004 +.007 −.022 +.522 +.491 −.002` | +1.483 | 相同(.521/.490 vs .522/.493) |
| G2 | 0.99953 | `+.008 −.010 +.130 +.756 +.109 +.007` | +0.987 | 相同 |
| B  | 0.99939 | `+.006 −.002 −.000 +.506 +.481 +.009` | +1.484 | 相同 |

每個平面內偶數/奇數輸出樣本的核相同 → 每個顏色只有一個相位(預期)。不同的是**顏色之間**。

**衰減偏差有多大**:同一資料的一般最小平方(3 幀平均當回歸變數)給 R `[.055 .224 .419 .221 .054]`、
G1 `[.088 .405 .397 .089]` —— 假寬。扣掉回歸變數雜訊後才是上表。

**z2048 垂直邊際(bonus,參考列 2y−1+v,v=−2..3):**

| 平面 | 垂直核 | 質心 |
|---|---|---|
| R  | `+.007 +.004 +.131 +.729 +.109 +.019` | +0.986 |
| G1 | `+.007 −.005 +.155 +.733 +.100 +.010` | +0.953 |
| G2 | `+.004 −.001 +.003 +.473 +.513 +.007` | +1.514 |
| B  | `+.003 −.000 +.014 +.486 +.486 +.010` | +1.483 |

水平同一次擬合與 z2048x1024 相同(R `.124 .738 .122`、G1 `.518 .493`…)→ **等向**。

注意:z2048x1024 的垂直**不是恆等**。名目 1:1(1023)的軸,只要 RWZM 有在動,也套了相位 0 的三角核
(IV 垂直邊際 ≈ `[.16, .70, .14]`,雜訊在下一同色列有 +0.06~0.10 共變異)。
z1024(兩軸 1023)則完全沒有(雜訊所有 lag 的相關 <0.002)→ 兩軸都 1:1 時縮放器是旁路的。
所以「z2048x1024 = CPU ×2 的等價物」只在水平成立,它的垂直也比參考模糊。

## 4. 時間雜訊交叉驗證

`rk_noisecov.py`:每像素 3 幀時間雜訊,用參考的 var/mean(g = 0.1043,四色一致)正規化,
lag 0 就是 Σw²(不依賴對位與紋理)。`rk_noise.py` 是分訊號區間的光子轉移版本,數字相同。

| | σ 比(輸出/參考) | Σw² | H lag-2 共變 | V lag-2 共變 | G1↔G2 (1,±1) |
|---|---|---|---|---|---|
| z2048x1024 R  | 0.646 | 0.417 | .006 | .086 | — |
| z2048x1024 G1 | 0.506 | 0.256 | .000 | .069 | .017 |
| z2048x1024 G2 | 0.607 | 0.368 | .003 | .061 | .016 |
| z2048x1024 B  | 0.554 | 0.307 | .000 | .095 | — |
| z2048 R  | 0.646 | 0.417 | .006 | .007 | — |
| z2048 G1 | 0.505 | 0.255 | .000 | .004 | .006 |
| z2048 G2 | 0.505 | 0.255 | .004 | .000 | .006 |
| z2048 B  | 0.508 | 0.258 | .000 | .000 | — |
| z1024 全部 | 1.00 | 0.99–1.01 | 0 | 0 | 0 |

判讀:

- **z2048 B = 0.258 ≈ 0.25**:正是 2×2 等權重的預測。B 沒有任何 lag 共變 → 2 抽頭不重疊,符合。
- **R 在兩案都是 0.417**:H 三角 × V 三角(z2048x1024 的 V 是 1023 的相位 0,z2048 R 的 V 也是相位 0)
  → 兩案應該相同,確實相同。由 Σw²=0.417 與 H lag-2 共變 0.006(=a²·Σv²)解出
  H ≈ `[0.10, 0.80, 0.10]`、V ≈ `[0.11, 0.78, 0.11]`。紋理擬合的可分離邊際是 `[.12,.75,.12]`,
  但完整 2D 紋理核的 Σw²(R:0.385 / 0.40)與雜訊 0.417 相差 <8%:核不完全可分離、中心較重,
  邊際看起來比較寬。核的寬度取 **中心 0.75–0.80、兩側 0.10–0.13**。
- **原題的三個預測(只有水平被動、垂直不動)不適用於 z2048x1024**,因為垂直也被濾波了。
  要比較,用同列不同行的 B/R(同一垂直核):σ² 比 0.307/0.417 = 0.74 = Σw²(相位 8)/Σw²(相位 0),
  與 `[.5,.5]`(0.50)/ 三角(0.66–0.68)= 0.74 吻合。
  等價的「只看水平」σ 比:相位 8 那半 ≈ ×0.71(等權重)、相位 0 那半 ≈ ×0.80–0.82(三角);
  點取樣 ×1.0 被排除。
- **綠色另外多降一截**:G1/G2 的 Σw² 比同色核預測低約 12–20%(z2048:預測 0.323,量到 0.255),
  並且 G1↔G2 對角鄰居有 +0.006~0.017 的共變,參考裡是 0。→ 縮放路徑有約 10% 的 G1/G2 互混
  (mosaic IV 擬合也看到另一個綠 +0.07~0.09,但那個擬合共線性重、單點不可信)。
  是 RWZM 本身還是開縮放時一起啟用的綠平衡區塊,這組資料分不出來。

## 5. 其他觀察 / 注意事項

- 輸出比參考整體亮 +1.4 DN(四色一樣,擬合截距 ≈ +1,增益 0.999–1.000)。兩支是不同次錄影,
  可能是場景/黑位小飄移,不是核。
- 參考與輸出是**不同次錄影**(相隔約 2 分鐘,每案有重新對焦檢查點)。紋理擬合混入任何鏡頭/對焦差;
  雜訊法不受影響。兩法對 E(2 抽頭)完全一致、對三角核差在 ≤8%,所以沒有看到明顯的跨錄影光學差。
- 1023 的參考:兩軸 1023 時縮放器看起來是旁路(雜訊完全白)。
- 捨入方式(`(a+b+1)>>1` vs 截斷)量不到:需要同一幀的輸入與輸出。
- 左 1/3 畫面紋理不足,擬合發散;報告數字用全幅(右 1/3 一致)。

## 6. 對 sensorlab / 產品的意義

- 要「真 2:1 合併」,RWZM 2048 只給了 1/4 的色平面(B)。若目標是 CPU ×2 等價的等權重合併,
  RWZM 不是;它是**對稱、幾何正確、但逐色核不同**的重取樣。
- 想讓所有顏色都拿到等權重,要讓每個顏色都落在相位 8 —— 以這個「感光座標均勻網格」的模型,
  單靠 RWZM 比例做不到(偶數色永遠在格點上);只能靠感光元件合併或垂直 CRCT bin。
- 原 note §7.5.6「整數比例只叫得動 1 個相位」要修正:**整數比例對每個顏色只用 1 個相位,
  但 2:1 時不同顏色用不同相位(0 與 8)**,因為相位是在感光座標算、在同色平面上取樣。
