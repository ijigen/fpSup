# SensorLab 自訂裁切比例：2026-11-01 範圍回歸

使用者已確認操作是「SensorLab 選單自訂裁切後直接套用」。回報寬5088–6048、高3520–4040附近 liveview 被拉寬／拉滿。

本次新增範圍驗證與證據封裝，沒有新改產品程式。現有 v0.7.3test 候選早於本次回歸；2026-10-30 的實機試驗未完成 LCD 驗收並已回退。不能把本次結果寫成相機修復成功。

## 本次離線結果

- 321個不同DC裁切：寬5088..6048步進16、高固定4040；高3520..4040步進2、寬固定6048；交點只算一次。
- 各用30.018p與先前試驗約19.026p，共642個apply選擇，全部通過。RES刻意選擇2K類型的16×2對齊光柵，配方固定11-bit 3x2，不代表使用者當下完整設定。
- 真apply ARM生成slot比例；執行W v4原生classifier／ratio兩個呼叫點及完整原生整數fit。fit只允許指定ROM／產品／veneer執行，只允許私有stack與16-byte輸出寫入，並核對SP、保存暫存器與輸入不變。
- 移除候選fit hook的離線反例：5088×4040生成848:671，重新變成1620×1080滿框；還原hook後為1364×1080、x128。原始碼與卡片沒有被反例修改。
- 另外20項比例、分派與外層畫框回歸通過，沒有skip。原有測試產生一則CSV未關閉的ResourceWarning，測試結果不受影響。
- 模擬器的顯示畫布是明示的1620×1080／3:2；沒有執行選單事件、實際display選擇／queue、DMA或實體LCD。apply的硬體邊界沿用既有明示fixture。
- 程式來源前後指紋相同，詳見reported-ranges.json。

真slot比例和直接DC寬高比不完全相同：此配方5088×4040應fit成1364×1080，而先前直接用DC比值的ROM測試是1360×1080。兩者測試輸入不同，不能混寫成同一實機觀察。
