# OG3K native UI release test package

This package contains the same OpenGate core, 360-record native UI payload, private NBR pack, and three UI hooks as its paired debug candidate. The UI payload is camera-tested.  The previous single-callsite shutter-angle fix failed a confirmed real FHD/OG3K idle-live-view comparison (16663 us versus 6411 us, with gain unchanged).  The revised core fix covers four local BL callsites.  After a battery-out cold boot, its real FHD/OG3K 29.97/180-degree idle-live-view A/B received a provisional visual pass; exact shell readback and all other frame rates remain pending.  Stage2 places all sections, then cleans/invalidates D-cache and invalidates the whole I-cache before entry. It is built with `--no-shell`: no USB worker, USB interface/endpoint patches, or worker state block remains resident.  It is still an alpha release and must pass the remaining angle rates, faster-media duration, playback, and inactive UHD/FHD regressions before promotion.  A CINE/STILL transition while OG3K remains selected is not yet validated; select FHD or UHD before leaving CINE until it is tested.  Warm restart and hot reinstall are not supported; begin only from a battery-out cold boot.

Install only `AutoRun.txt` and `fpSup.BIN` at the card root, then perform a battery-out cold boot.  Removing or renaming `AutoRun.txt` followed by another complete cold boot restores stock firmware behavior.
