RAW view: fp latitude on a 709 screenRAW 監看:fp 寬容度放上 709 屏幕

A RAW row in the COLOR menu makes the fp’s LCD show what 12-bit CinemaDNG will record: recording gain in standby, sensor saturation as white, and the whole latitude laid onto a Rec.709 screen in one of two ways. Below: how each ISO’s latitude lands on the screen, and what the two AEL settings do.

COLOR 選單多一列 RAW,讓 fp 的屏幕顯示 12-bit CinemaDNG 實際會錄到的東西:待機用錄影增益、感光元件飽和即白,整段寬容度用兩種方式之一放上 Rec.709 屏幕。下面是每個 ISO 的寬容度落在屏幕哪裡,以及 AEL 兩個設置的作用。

  • fpsup-raw-view v0.2.0test
  • firmware 5.02韌體 5.02
  • CinemaDNG 12-bit

How to adjust怎麼調

  1. Press COLOR and pick row 17, RAW.按 COLOR,選第 17 列 RAW。
  2. The box on the right picks the curve: SA or GA.右側的框選曲線:SA 或 GA。
  3. Press AEL. Only two settings are used: Contrast and Saturation, each 0 or +0.2. Sharpness is fixed at 0.按 AEL,只用兩項:對比度與飽和度,都只有 0 或 +0.2。清晰度固定 0。

Contrast: the bottom 1.6 stops對比度:最底 1.6 檔

The live view’s tone table has 2048 entries with clipping at entry 1918, so the darkest entry it can tell apart sits 10.9 stops below clipping. The fp holds 12.5 stops, so the bottom ~1.6 stops (the lighter segment of each column) fall between entries 0 and 1. Measured on the camera: the table is not interpolated, so this range shows up only as noise-dot density.

機身預覽的色調錶有 2048 格,削波在第 1918 格,最暗能分辨的一格離削波 10.9 檔。fp 有 12.5 檔,所以最底約 1.6 檔(每列顏色較淺的一段)都落在第 0 格和第 1 格之間。實測查表不插值,這段只會以噪點疏密出現。

0bottom 1.6 stops shown顯示最底 1.6 檔

  • SA: all 12.5 stops on screen with 709’s stop spacing; the floor sits at the LCD black level.SA:12.5 檔全部按 709 檔距放進屏幕,底部落在液晶黑位。
  • GA: a toe lifts the darkest live-view entry to 10%, then rejoins the guide’s curve; above middle grey it is the guide’s.GA:暗部加一段墊腳,預覽最暗一格顯示 10%,再接回指南曲線;中灰以上與指南相同。
  • The bottom stops show as dots that thin out as it gets darker: dots mean detail, pure black means crushed.最底幾檔以越暗越稀疏的噪點出現:有點就是有細節,純黑才是壓死。

+0.2bottom 1.6 stops dropped去掉最底 1.6 檔

  • SA: only the 10.9 stops the live view resolves, with 709’s stop spacing; each stop gets more room.SA:只放預覽分得出的 10.9 檔,按 709 檔距,每檔更寬。
  • GA: exactly the guide’s LUT. The darkest stops sit below the LCD black level.GA:完全按指南 LUT,最暗幾檔落在液晶黑位以下。
  • The bottom stops are black: you can’t tell detail from crushed there.最底幾檔全黑,分不出有沒有壓死。

Effect on CinemaDNG: none. Contrast only changes the monitoring tone table; files shot with either setting are identical.

對 CinemaDNG 的影響:沒有。對比度只改監看用的色調錶,兩種設置錄下的檔案完全相同。

Saturation: the colour matrix飽和度:色彩矩陣

In RAW mode, Saturation does not adjust vividness; it chooses whether the camera’s own colour calibration is used.

RAW 模式下,飽和度不是調顏色濃淡,而是決定要不要用相機自己的色彩校正。

0no matrix (default)不套矩陣(預設)

  • Sensor RGB shown directly, as in the stock OFF mode.直接顯示傳感器 RGB,與原廠 OFF 相同。
  • The CinemaDNG is exactly the same as a normal recording.CinemaDNG 與一般錄下的檔案完全相同。
  • Colours look washed out; use it for brightness and exposure.顏色偏淡,適合只看亮度與曝光。

+0.2fp calibration matrixfp 校色矩陣

  • The camera’s own calibration matrix (the one the other colour modes use) is applied on screen.屏幕套用相機自己的校色矩陣(其他色彩模式用的那一組)。
  • The same matrix is written into the CinemaDNG ColorMatrix, so Resolve shows the colours you monitored. Raw pixels are untouched.同一組矩陣寫進 CinemaDNG 的 ColorMatrix,Resolve 顯示的顏色與監看一致。RAW 像素不動。
  • Use it to judge skin tones and colour.適合判斷膚色與色彩。
