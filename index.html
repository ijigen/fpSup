Firmware韌體
Ver.5.02 only. Not "5.02 or newer" — only this version. A card is built for the exact places things sit in Ver.5.02, and on any other version it writes to the wrong ones. Check under MENU → SYSTEM → Information.
只有 Ver.5.02。不是「5.02 或更新」—— 只有這一版。 卡片是照著 Ver.5.02 裡東西所在的確切位置做的, 在其他版本上它會寫到錯的地方。
在 MENU → SYSTEM → Information 底下確認。
Card記憶卡
Open gate 3K needs an SSD, not a card. It wants about 221 MB/s at 24p; the UHS-II SD card we measured does 94, and only 66 at the 9.2 MB one-frame writes CinemaDNG actually makes. That is a 3× gap, not a few percent — every open gate 3K clip we recorded to that card stopped at 4.1 seconds or less. An external SSD over USB-C measured 390. OG2K needs only 98 MB/s, the same as normal FHD, and is the open gate you can record to a card. A slow card is the most common problem people have.
Open gate 3K 需要 SSD,不是記憶卡。它在 24p 要大約 221 MB/s;我們量過的 UHS-II SD 卡是 94,而在 CinemaDNG 實際會做的 9.2 MB 單格寫入之下只有 66。
那是 3 倍的差距,不是差幾個百分點 —— 我們錄到那張卡上的每一段 open gate 3K,全部停在 4.1 秒以內。 USB-C 外接 SSD 量到 390。
OG2K 只需要 98 MB/s,跟一般 FHD 一樣, 那才是記憶卡錄得動的 open gate。
卡太慢是大家最常遇到的問題。
Risk風險
Nothing is installed on the camera. It only lives in memory while the power is on, so there is no firmware to flash back. You remove it by deleting a file — but in the right order. The camera remembers menu settings on its own, so put those back to normal first. The guide shows you how.
相機上什麼都不會被安裝。它只在開著電的時候活在記憶體裡, 所以沒有韌體需要刷回去。
移除的方式是刪掉一個檔案 —— 但要照順序。 相機會自己記住選單設定,所以要先把那些設回正常。指南裡有寫怎麼做。

fpsup-usbshell is not for shooting. It is a development tool that lets a computer talk to the camera over USB. It adds nothing you can see or use on the camera. If you are here to record, you want og3k or og2k, and gyro.

fpsup-usbshell 不是拿來拍片的。 那是一個開發工具,讓電腦透過 USB 跟相機對話, 在相機上看不到也用不到任何東西。
如果你是來錄影的,你要的是 og3k 或 og2k, 再加上 gyro。

Both open-gate builds show the same picture. OG2K is smaller: a third of the data, less rolling shutter (8.3 ms instead of 12.4), and the sensor's quiet readout at every frame rate including 100p. Pick OG2K if your card is not fast enough for OG3K. They cannot go on the same card. Both are still being tested. Open gate on an fp was first done by Vitaly Li.

兩個 open gate 版本呈現的畫面是一樣的。OG2K 比較小: 資料量是三分之一、捲簾比較少(8.3 ms 而不是 12.4), 而且在每一個格率(包含 100p)都走感光元件的安靜讀出。
如果你的卡不夠快跑 OG3K,就選 OG2K。兩者不能放在同一張卡上, 而且都還在測試中。
在 fp 上做出 open gate 的第一個人是 Vitaly Li。
