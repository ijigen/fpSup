Camera compatibility相機相容性

Camera相機
SIGMA fp only. Not the fp L — it has a different sensor, and nothing here works on it.
只限 SIGMA fp。不是 fp L —— 它的感光元件不同, 這裡的東西在它上面都不能用。
Firmware韌體
Ver.5.02 only — not “5.02 or newer”. The card writes to fixed addresses in Ver.5.02; on any other version those addresses are wrong. Check in MENU → SYSTEM → Information.
只限 Ver.5.02 —— 不是「5.02 或更新」。 卡片寫入的是 Ver.5.02 裡的固定位址,換了版本位址就是錯的。
在 MENU → SYSTEM → Information 確認。
Loading載入方式
The current fpSup-Merge card loads tools into memory from AutoRun.txt and the fpSup folder on the SD card. It does not write to the camera's flash. Installation and removal instructions.
目前的 fpSup-Merge 卡片透過 SD 卡上的 AutoRun.txt 和 fpSup 資料夾,把功能載入記憶體,不寫入相機的 flash。 安裝與移除說明。
