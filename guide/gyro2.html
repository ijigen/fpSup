在 DaVinci Resolve 裡幫 SIGMA fp 的影片防震。要兩樣東西一起用:

Gyro2 sup

Records the camera's shake into every CinemaDNG frame. Make the card →

錄 CinemaDNG 時,把相機的晃動記錄進每一格。做卡 →

(fpSup)

A DaVinci Resolve plugin. Reads the shake and stabilises the clip. Install it ↓

DaVinci Resolve 外掛。讀出晃動、把畫面穩住。安裝 ↓

The sup alone does not stabilise anything: without the plugin the clip looks the same as before.

只裝 sup 不會讓畫面變穩:沒有外掛,影片跟原本一樣。

Install the Resolve plugin裝 Resolve 外掛

  1. Download and install下載並安裝

    MacMac 安裝

    1. Download fpSupGyroflow-OpenFX-macos.pkg and open it. It is blocked: press Done.
    2. System Settings → Privacy & Security, scroll down, press Open Anyway.
    3. Follow the installer.
    1. 下載 fpSupGyroflow-OpenFX-macos.pkg,打開。會被擋下,按完成。
    2. 系統設定 → 隱私權與安全性,捲到最下面,按強制打開。
    3. 照安裝程式按下去。

    Open Terminal, paste this, press Enter, type your password. It downloads and installs the latest version.

    打開終端機,貼上這段,按 Enter,輸入密碼。會自動下載並裝好最新版。

    curl -L -o /tmp/fpSupGyroflow.zip https://github.com/ijigen/gyroflow-plugins/releases/latest/download/fpSupGyroflow-OpenFX-macos.zip
sudo mkdir -p /Library/OFX/Plugins
sudo rm -rf /Library/OFX/Plugins/fpSupGyroflow.ofx.bundle
sudo unzip -q /tmp/fpSupGyroflow.zip -d /Library/OFX/Plugins

    WindowsWindows 安裝

    1. Download fpSupGyroflow-OpenFX-windows.zip and unzip it.
    2. Right-click Install-Windows.bat → Run as administrator. (SmartScreen: More info → Run anyway.)
    1. 下載 fpSupGyroflow-OpenFX-windows.zip,解壓縮。
    2. 在 Install-Windows.bat 按右鍵 → 以系統管理員身分執行。(跳警告就按其他資訊 → 仍要執行。)

    Mac needs one extra step because the plugin is not notarized by Apple. It installs next to the official Gyroflow plugin; you can keep both. Tested on Apple-silicon Macs only.

    Mac 多一步是因為外掛沒有經過 Apple 公證。它跟官方 Gyroflow 外掛並存,兩個都可以留著。 只在 Apple 晶片的 Mac 上實測過。

    The plugin is a modified version of Gyroflow's gyroflow-plugins (GPL-3.0); source at github.com/ijigen/gyroflow-plugins. Report problems with it to fpSup, not to Gyroflow.

    外掛是以 Gyroflow 的 gyroflow-plugins(GPL-3.0)修改而成,原始碼在 github.com/ijigen/gyroflow-plugins。外掛的問題請回報給 fpSup,不要回報給 Gyroflow。

  2. Check Resolve sees it確認 Resolve 看得到

    Restart Resolve. In Preferences → Video Plugins, fpSupGyroflow.ofx.bundle must be ticked. In Effects → OpenFX it is in the fpSup group as Gyroflow (fpSup).

    重開 Resolve。在偏好設定 → Video Plugins 裡 fpSupGyroflow.ofx.bundle 要打勾。在特效 → OpenFX 的 fpSup 分組裡,名字是 Gyroflow (fpSup)。

Use使用

  1. Record CinemaDNG錄 CinemaDNG

    Record as usual. Nothing new appears on the card: the data is inside the frames.

    照平常錄。卡上不會多出任何檔案:資料就在畫面檔裡面。

  2. Add the effect in Resolve在 Resolve 加上效果

    Put the clip on the timeline and add Gyroflow (fpSup). It finds the gyro data by itself; Status turns OK. Then set Smoothness and Zoom limit under Adjust parameters to taste.

    把片子放上時間軸,加上 Gyroflow (fpSup)。它會自己找到陀螺資料, Status 變成 OK。再到 Adjust parameters 依喜好調 Smoothness 和 Zoom limit。

    The rolling-shutter time, the lens (focal length, distortion, focus) and the frame timing all come from the frames. There is nothing to sync and no lens profile to load.

    果凍效應時間、鏡頭(焦距、畸變、對焦)和每格的時間都從畫面裡來。 不用同步,也不用載入鏡頭檔。

  3. A manual lens手動鏡頭

    A lens without electronic contacts gives the camera no lens data. In the fpSup lens group, set Manual lens focal (mm) to its focal length. Leave Typical distortion for focal on; if straight lines near the edges still bend or wobble, turn it off and set Corner distortion (%) by eye (negative = barrel). If you have a Gyroflow lens profile for it, Load preset/lens profile loads it instead.

    沒有電子接點的鏡頭,相機拿不到鏡頭資料。在 fpSup lens 群組把 Manual lens focal (mm) 填成它的焦距。Typical distortion for focal 維持打勾; 如果畫面邊緣的直線還是會彎或晃,取消打勾,改用 Corner distortion (%) 目測調整 (負值 = 桶狀)。如果你有這顆鏡頭的 Gyroflow 鏡頭檔,用 Load preset/lens profile 載入即可。

What the plugin hands to Gyroflow外掛交給 Gyroflow 的資料

The plugin turns what the camera wrote into Gyroflow's own camera format (Gyroflow Protobuf), the same one cameras with built-in Gyroflow support use. What goes in:

外掛把相機寫的資料轉成 Gyroflow 自己的相機格式 (Gyroflow Protobuf), 就是內建支援 Gyroflow 的相機用的同一種。放進去的有:

data資料from來源what Gyroflow does with itGyroflow 拿來做什麼
gyroscope, every sample (2499.5 Hz)陀螺儀,每一筆樣本(2499.5 Hz) the camera's gyro相機的陀螺儀 the camera's motion: what gets undone相機的轉動:要抵銷的就是它
accelerometer加速度計 the camera's level sensor (about 45 a second)相機的水平儀(每秒約 45 次) which way is down: horizon lock哪邊是下:水平鎖定
each frame's start and end time每一格的開始與結束時間 the sensor's frame clock (Vd)感光元件的幀時鐘(Vd) lines motion up with the picture — no sync step讓動作跟畫面對齊 —— 不用同步
readout time and direction讀出時間與方向 the sensor mode (e.g. 12.4 ms in Open Gate 3K)感光元件模式(例如開放片幅 3K 為 12.4 ms) rolling-shutter (jello) correction果凍效應修正

Not included: orientation already worked out by the camera (Gyroflow computes it from the gyro), and what the camera's electronic stabiliser or a lens's optical stabiliser did — that is not recorded, so turn both off when you shoot for Gyro2.

沒有放的:相機算好的姿態(Gyroflow 會自己從陀螺儀算), 以及相機電子防震或鏡頭光學防震做了什麼 —— 這些沒有記錄, 所以用 Gyro2 拍的時候兩者都要關掉。

Updating the plugin更新外掛

In the plugin's fpSup plugin group: Check for update, then Install. The download runs in the background (about a minute) while Resolve keeps working; press Install once. Type a version in Version to install (e.g. 0.1.2) to install that one, older ones too. Roll back puts the previous installation back without the network. Restart Resolve afterwards; the Update status line then shows the result.

在外掛的 fpSup plugin 群組:按 Check for update,再按 Install。 下載在背景進行(約一分鐘),Resolve 可以繼續用;Install 按一次就好。 在 Version to install 填版本(例如 0.1.2)就安裝那一版,舊版也可以。 Roll back 不用網路就能退回上一個安裝。做完重開 Resolve,Update status 會顯示結果。

Known limits已知限制

  • Hand-held close-ups (under about 1 m): the lens also moves sideways, which a gyro cannot see, so some shake stays.
  • 手持拍近物(約 1 公尺內):鏡頭同時在平移,陀螺量不到,會留一點晃。
  • Fast shake at a slow shutter leaves motion blur that no stabilisation can remove.
  • 慢快門下的快速晃動會有動態模糊,防震修不掉。
  • Strong shake with a low Zoom limit: the plugin keeps some motion so the frame edge never shows. Raise Zoom limit for a steadier, tighter picture.
  • 晃很大而 Zoom limit 偏低:外掛會留一些晃動,讓畫面邊緣不露出來。 調高 Zoom limit 會更穩、畫面更裁切。
  • If the camera skips frames while recording, Resolve splits the clip; each part stabilises on its own.
  • 錄影時相機若跳幀,Resolve 會把片子分成兩段,各段各自防震。

Remove移除

Camera: delete fpSup/20GYR2.BIN from the card (or the whole fpSup card), then switch the camera off. There is no menu setting to set back. Plugin: delete fpSupGyroflow.ofx.bundle from the plugin folder and restart Resolve.

相機:刪除卡上的 fpSup/20GYR2.BIN(或整張 fpSup 卡的內容),再關機。 沒有選單設定要改回。外掛:從外掛資料夾刪掉 fpSupGyroflow.ofx.bundle,重開 Resolve。
