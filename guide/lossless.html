fpSup-Lossless

Records CinemaDNG losslessly compressed by the camera's own hardware codec, which the stock firmware never uses for video. A 3K 12-bit frame of 9.1 MB typically becomes about 3.2 MB. Not a single pixel value changes. Version v0.2.0test — a test build.

用相機自己的硬體編碼器錄無損壓縮的 CinemaDNG(原廠韌體從不拿它錄影)。 一張 9.1 MB 的 3K 12-bit 畫格通常變成約 3.2 MB,像素值一個都不變。 版本 v0.2.0test —— 這是測試版。

Thanks致謝

Thank you, CorNy感謝 CorNy

CorNy found that DaVinci Resolve plays a clip mixing compressed and uncompressed frames without flickering only when its first frame is uncompressed. So every take now keeps its first frame uncompressed — and mixed clips play cleanly in Resolve.

CorNy 發現:壓縮與未壓縮畫格混合的片段,只有在第一格是未壓縮時, DaVinci Resolve 才能正常播放、不會閃爍。所以現在每段拍攝的第一格都保留未壓縮 —— 混合片段在 Resolve 裡就能乾淨地播放。

Install安裝

Tick fpSup-Lossless in fpSup-Merge, download, and put it on the card as the install instructions on that page say.

在 fpSup-Merge 勾選 fpSup-Lossless 下載，照 頁上的安裝說明放進卡。

Use使用

Open MENU → SHOOT, page 2 (CINE). Below Audio Record there is a new row, Lossless RAW: set it to On, then record CinemaDNG as usual.

打開 MENU → SHOOT 第 2 頁(CINE)。在「錄音」下面多了一列 Lossless RAW:設成 On,然後照平常錄 CinemaDNG。

  • It starts Off. Your choice is kept across power-off in fpSup-Lossless's own file on the card (\fpSup\10LOSS.BIN), never in the camera's settings.預設是 Off。 你的選擇會存在卡上 fpSup-Lossless 自己的檔案裡(\fpSup\10LOSS.BIN),關機後保留; 相機設定裡不存任何東西。
  • When the codec cannot finish a frame in time, that frame is written uncompressed, exactly as the camera writes it today. A clip can therefore mix compressed and uncompressed frames; no frame is dropped to make room.編碼器來不及壓完的畫格, 照相機原本的方式寫成未壓縮。所以一段片子可能混著壓縮與未壓縮的畫格;不會為了趕上而丟格。
  • The first frame of every take is always uncompressed, so DaVinci Resolve plays mixed clips (thanks to CorNy).每段拍攝的第一格一定是未壓縮, DaVinci Resolve 才能播放混合片段(感謝 CorNy)。
  • Compressed clips play back in the camera: the player decodes them with the same hardware.壓縮過的片段可以在機內回放:播放器用同一顆硬體解碼。

What is tested and what is not測過什麼、沒測過什麼

This is a test build. Record something you do not need and check it before you shoot something that matters.
這是測試版。拍重要的東西之前,先錄一段不需要的東西並檢查它。

v0.1.3test reduces the memory used when loading the Lossless menu. The reported 100p + 10-bit + Lossless freeze is still being investigated; this build has not been tested on a camera at that setting.

v0.1.3test 減少載入 Lossless 選單時的記憶體使用量。100p + 10-bit + Lossless 凍結的回報仍在調查中;這個版本尚未在相機上以該設定實測。

Remove移除

Nothing to undo first: Lossless saves no setting. Delete the files (or take the card out) and switch the camera off. More on removing.

不用先改回什麼:Lossless 不存任何設定。刪掉檔案(或拔卡),然後關機。 移除的詳細說明。
